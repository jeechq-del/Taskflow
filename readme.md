  # TaskFlow – Planificador de Tareas

  Proyecto individual – Sprint 2.

  ## Funcionalidades
  - Validación del formulario con `validateTaskForm()` y mensajes de error.
  - Clase `TaskManager` con los métodos: getAllTasks, getTasksWithStatus, addTask,
  deleteTask, updateTask, assignTask.
  - Agregar tareas desde el formulario y mostrarlas como tarjetas.
  - Eliminar tareas (de la pantalla y del array).
  - Cada tarea tiene un ID único que se incrementa.

  ## Tecnologías
  HTML, CSS (Bootstrap 5) y JavaScript.

  ## Cómo usarlo
  Abrir `index.html` en el navegador.
